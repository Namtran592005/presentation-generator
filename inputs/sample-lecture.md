# Introduction to Machine Learning

## Chapter 1: What is Machine Learning?
- Machine learning is a subset of artificial intelligence
- Systems learn from data without explicit programming
- Three main types: supervised, unsupervised, reinforcement learning
- Applications include image recognition, NLP, and recommendation systems

## Chapter 2: Supervised Learning
- Model trained on labeled data
- Common algorithms: linear regression, decision trees, SVM
- Used for classification and regression tasks
- Requires high-quality training data

## Chapter 3: Key Concepts
- Training set vs test set split (typically 80/20)
- Overfitting: model memorizes training data but fails on new data
- Underfitting: model is too simple to capture patterns
- Cross-validation helps evaluate model performance

## Chapter 4: Evaluation Metrics
| Metric | Formula | Best Value |
|--------|---------|------------|
| Accuracy | (TP+TN)/(TP+TN+FP+FN) | 1.0 |
| Precision | TP/(TP+FP) | 1.0 |
| Recall | TP/(TP+FN) | 1.0 |
| F1 Score | 2*P*R/(P+R) | 1.0 |
